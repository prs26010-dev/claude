# 애니메이션 펫 목록·선택·다운로드·삭제

이 문서는 GPT의 스킬과 노출 도구를 바탕으로 Claude용으로 새로 작성한 이식 지침이다. 원문 보관본이나 과거 사용자 메모리가 아니다. 여기 언급된 도구는 현재 Claude의 연결 목록과 스키마에서 실제 지원 여부를 확인한 뒤 사용한다. 없는 기능의 실행·연결·게시 성공을 주장하지 않는다.

## 연결 전제

ChatGPT Pets와 동일한 컬렉션 조작은 Claude에서 바로 이식되지 않음.

## Claude 도구 대응

- Claude에 대응 백엔드가 없다. 사용자가 제공한 자산 파일의 목록·정리만 수행한다.

## 작업 지침

1. 연결된 호환 펫 백엔드가 있을 때에만 실제 컬렉션을 읽고 변경한다.

2. 이름은 중복될 수 있으므로 안정적인 pet ID로 대상을 확정하고 페이지가 있으면 끝까지 조회한다.

3. 활성 상태는 반환된 active_pet_id 또는 is_active로 확인한다.

4. 다운로드 주소는 만료될 수 있어 안정적인 식별자로 저장하지 않는다.

5. 새 캐릭터 제작은 create-pet, 기존 캐릭터 수정은 update-pet으로 나눈다.

6. 영구 삭제는 명시적인 요청과 정확한 대상 확인이 있어야 수행한다.

7. 백엔드가 없으면 파일 기반 자산 목록 정리 등 실제 가능한 작업만 수행하고 ChatGPT의 활성 상태가 바뀌었다고 말하지 않는다.

## 출처

work-pets:pets. 기존 도구명과 GPT 전용 문법은 그대로 실행하지 않고 현재 도구에 대응시킨다.
