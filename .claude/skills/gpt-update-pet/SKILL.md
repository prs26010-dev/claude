# 기존 펫 메타데이터·스프라이트 수정

이 문서는 GPT의 스킬과 노출 도구를 바탕으로 Claude용으로 새로 작성한 이식 지침이다. 원문 보관본이나 과거 사용자 메모리가 아니다. 여기 언급된 도구는 현재 Claude의 연결 목록과 스키마에서 실제 지원 여부를 확인한 뒤 사용한다. 없는 기능의 실행·연결·게시 성공을 주장하지 않는다.

## 연결 전제

ChatGPT Pets 수정 API는 자동 이식되지 않음. 원본 자산과 편집 도구 필요.

## Claude 도구 대응

- Claude에 대응 백엔드가 없다. 사용자가 제공한 원본 스프라이트 파일을 수정·검증해 파일로 전달한다.

## 작업 지침

1. 기존 대상의 안정적인 ID와 사용자 정의 자산 여부를 확인하고 수정 과정 내내 같은 ID를 유지한다.

2. 이름·설명만 바꾸는 작업에는 이미지를 다시 만들지 않는다.

3. 이미지 수정은 원본을 확보해 정체성을 유지하고, 사용자 요청 범위의 소스 행을 수정한 뒤 전체 시트를 재구성한다.

4. 구조 검증과 실제 재생 미리보기를 수행하고 최종 인코딩 바이트가 검증한 파일과 같은지 확인한다.

5. 사용자 요청이 없는 활성 선택 변경이나 새 펫 생성을 하지 않는다.

6. 호환 백엔드가 없으면 수정한 자산 파일과 검증 범위만 전달한다.

## 출처

work-pets:update-pet. 기존 도구명과 GPT 전용 문법은 그대로 실행하지 않고 현재 도구에 대응시킨다.
