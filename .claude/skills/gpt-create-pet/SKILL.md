# 애니메이션 캐릭터 제작·스프라이트 품질 관리

이 문서는 GPT의 스킬과 노출 도구를 바탕으로 Claude용으로 새로 작성한 이식 지침이다. 원문 보관본이나 과거 사용자 메모리가 아니다. 여기 언급된 도구는 현재 Claude의 연결 목록과 스키마에서 실제 지원 여부를 확인한 뒤 사용한다. 없는 기능의 실행·연결·게시 성공을 주장하지 않는다.

## 연결 전제

아트 제작 지침 일부 이식 가능. ChatGPT Work Pets 등록·선택·Library는 전용 백엔드가 필요.

## Claude 도구 대응

- Claude에는 Work Pets 백엔드와 이미지 생성 도구가 기본 제공되지 않는다. 사용자가 원본 이미지를 제공하거나 이미지 생성 도구가 연결된 경우에만 시트 구성·검사(Python/Pillow 등)를 수행한다.

## 작업 지침

1. 원래 스킬은 ChatGPT Work 모드의 Pets용이다.

2. 실제 동물 조언이나 일반 그림 요청과 혼동하지 않는다.

3. Claude에서 비슷한 애니메이션 자산을 만드는 요청이면 별도 파일 제작 작업으로 범위를 명확히 한다.

4. 캐릭터 정체성과 크기·기준선을 유지하면서 원문의 9개 애니메이션 상태와 16개 시선 방향 요구를 참조한다.

5. 표준 행을 먼저 검수하고 시선 방향은 화면 좌표의 위→오른쪽→아래→왼쪽 기준으로 일관되게 구성한다.

6. 프레임 수, 잘림, 알파, 연결 부위, 이동 방향, 보행, 반복 연속성을 검사하고 실제 재생 미리보기를 제공한다.

7. 완성 아틀라스 전체를 단일 이미지 생성으로 해결했다고 간주하지 않는다.

8. 구조 계약, QA 도구와 호환 런타임이 없으면 ChatGPT Pets 호환을 확정하지 않는다.

9. 이미지 생성과 검증이 가능한 도구가 없으면 그 부분을 미구현으로 표시한다.

10. ChatGPT에 등록·활성화했다고 주장하지 않는다.

## 출처

work-pets:create-pet. 기존 도구명과 GPT 전용 문법은 그대로 실행하지 않고 현재 도구에 대응시킨다.
